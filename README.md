# Pizza Restaurant UI
A modern and visually appealing UI design for a pizza restaurant website. Built with HTML and CSS, this project showcases a responsive layout, clean design, and user-friendly interface ideal for a restaurant landing page or online menu.

---

## Features
- Attractive pizza restaurant homepage design  
- Responsive layout for desktop and mobile devices  
- Clean and semantic HTML structure  
- Styled using modern CSS techniques  
- Includes sections like menu, about, and contact info  
- Fully static with no backend integration

## How to Run Locally
1. Clone the repository:  
   ```bash
   git clone https://github.com/Bharath-S-J/Pizza_Restaurant_UI_Accio.git
   cd Pizza_Restaurant_UI_Accio
````

2. Open `index.html` in any modern web browser.
